Status

Provjera u toku…

Ploča je statična: stvarno stanje vidi s ‘mujowin status’. Provjera porta je best-effort.

🌐 Otvori Windows (noVNC) RDP → localhost:3389

Brzi start

  1. Kopiraj .env i postavi JAKU lozinku: cp .env.example .env
  2. ./scripts/mujowin doctor — provjeri KVM, Docker, RAM/CPU/disk
  3. ./scripts/mujowin profile standard — izaberi profil (ili preporuku iz doctora)
  4. ./scripts/mujowin up — pokreni; prvi boot skida image pa traje
  5. Otvori noVNC link iznad i prijavi se.

Česta pitanja

Da li mi treba Windows licenca?

Da. Ti sam odgovaraš za valjanu Windows licencu i Microsoftove uslove. Slika koristi generičke instalacijske ključeve koji nisu aktivacija.

Šta ako nema /dev/kvm?

Bez KVM-a VM radi u softverskoj emulaciji — ekstremno sporo ili nikako. Treba ti host s KVM-om. ‘mujowin doctor’ to jasno kaže.

Da li podaci preživljavaju restart?

Restart kontejnera i stop/start Codespacea: da (named volume). ‘mujowin reset’ ili brisanje Codespacea: ne. Backup pravi ‘mujowin backup’.

Ima li GPU?

Ne — Codespaces i tipični VPS-ovi nemaju GPU za VM. Grafika ide preko noVNC-a.

Rješavanje problema

  • up se odbija → postavi WINDOWS_PASSWORD u .env (ne defaultnu).
  • Crn ekran na 8006 → sačekaj boot, pa mujowin logs.
  • Port zauzet → promijeni WEB_PORT/RDP_PORT u .env.
  • Sporo → slabiji profil + zatvori ostalo; detalji u docs/TROUBLESHOOTING.md.
