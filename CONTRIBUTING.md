# Doprinos (CONTRIBUTING)

1. Fork → grana (`feat/…`, `fix/…`, `docs/…`).
2. Prije PR-a: `make lint && make test && make config`.
3. Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `test:`.
4. Jedan PR = jedna stvar. Bez novih zavisnosti bez obrazloženja
   (web ostaje na nula zavisnosti).
5. PR opis popuni po šablonu. Maintainer traži `doctor` izlaz kad je bitno.

Ponašanje: konkretno, bez prepucavanja. Pitanja u Discussions/issues.
